# Windows ARM64 standard-user writer trial

The dedicated Windows 11 ARM64 job exercises a new local standard account on the disposable runner. One authenticated Secondary Logon process runs from the runner's original nonzero session. The same user registers a single, on-demand S4U task in session 0. Both participants read their own Windows logon type and authentication ID, WTS session ID, process session ID and primary token. This measures local cross-session file exclusion. Interactive console/RDP and installed MSI handover have separate evidence. [Compiler archive](https://github.com/VoltKraft/immich-folder-watch/actions/runs/46062734833/artifacts/15229492640)

The fixture generates its password in a job-local SecureString and passes it to Windows through the process credentials API. The unprivileged task runs under its own SID with S4U inside a new private Task Scheduler folder. The broker verifies the folder's three trustees and removes it after the task exits. A temporary, SID-specific batch-logon assignment permits that logon. Cleanup verifies the original empty assignment, task removal, account and profile removal, staging directory removal and restoration of Secondary Logon. The hosted archive contains the verified compiler ZIP, source hashes and the scoped process and cleanup receipts. Run the replay from the measured checkout after extracting the archive.
