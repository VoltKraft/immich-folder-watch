# Windows ARM64 standard-user writer trial

The dedicated Windows 11 ARM64 job exercises a new local standard account on the disposable runner. One authenticated Secondary Logon process runs from the runner's original nonzero session. The provisioning host registers a single, on-demand task for that same ordinary user. Task Scheduler authenticates its batch logon in session 0. Both participants read their own Windows logon type and authentication ID, WTS session ID, process session ID and primary token. This measures local cross-session file exclusion. Interactive console/RDP and installed MSI handover have separate evidence. [Compiler archive](https://github.com/VoltKraft/immich-folder-watch/actions/runs/46062734833/artifacts/15229492640)

The fixture generates the temporary account's password in a job-local SecureString. The host supplies it directly to the Windows process credentials API and the local Task Scheduler registration method. Both task and process run with the ordinary user's privileges. Only SYSTEM and local administrators can manage the private task folder. The broker verifies those trustees, checks the fixed action and least-privileged principal, then removes the registration and folder after the task exits. A temporary assignment of the batch-logon right is scoped to the newly created SID. Cleanup verifies the original empty assignment, task removal, account and profile removal, staging directory removal and restoration of Secondary Logon. The hosted archive contains the verified compiler ZIP, source hashes and the scoped process and cleanup receipts. Run the replay from the measured checkout after extracting the archive.
